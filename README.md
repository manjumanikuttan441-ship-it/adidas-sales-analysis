# Adidas Sales Data Analysis

## 📌 Project Overview

This project analyzes **Adidas sales data** using Microsoft Excel to understand sales performance, product demand, retailer contribution, regional performance, and profitability.

The project starts with raw sales data and applies **data cleaning, transformation, analysis, and visualization** techniques to convert the dataset into meaningful business insights.

## 🎯 Project Objectives

* Analyze overall Adidas sales performance.
* Identify the best-performing products and product categories.
* Compare sales performance across different retailers.
* Analyze sales across regions, states, and cities.
* Evaluate operating profit and operating margin.
* Identify monthly, quarterly, and yearly sales trends.
* Understand the relationship between units sold, price, and total sales.
* Create meaningful reports and dashboards using Excel.
* Generate insights that can support better business decisions.

## 📊 Dataset Description

The Adidas sales dataset contains information about Adidas products and their sales performance. The major fields include:

| Column           | Description                                  |
| ---------------- | -------------------------------------------- |
| Retailer         | Name of the retailer selling Adidas products |
| Retailer ID      | Unique identification number of the retailer |
| Invoice Date     | Date of the sales transaction                |
| Region           | Geographic sales region                      |
| State            | State where the sale occurred                |
| City             | City where the sale occurred                 |
| Product          | Adidas product name                          |
| Price per Unit   | Selling price of one unit                    |
| Units Sold       | Number of units sold                         |
| Total Sales      | Total revenue generated                      |
| Operating Profit | Profit generated from sales                  |
| Operating Margin | Percentage of operating profit               |

## 🧹 Data Cleaning and Transformation

The raw Adidas sales data was cleaned and prepared in Excel before analysis.

The main steps included:

* Removing duplicate records.
* Identifying and handling missing values.
* Correcting inconsistent text and formats.
* Standardizing date formats.
* Checking numerical values and data types.
* Formatting sales, price, and profit values correctly.
* Creating additional fields such as **Year, Month, and Quarter**.
* Using formulas to calculate and verify important measures.
* Sorting and filtering data for analysis.

## 🔍 Key Analysis

The project focuses on the following key areas:

### Sales Analysis

Analysis of total sales and sales trends over different periods.

### Product Analysis

Identification of the best- and lowest-performing Adidas products.

### Retailer Analysis

Comparison of sales and profitability across different retailers.

### Regional Analysis

Evaluation of sales performance across regions, states, and cities.

### Profitability Analysis

Analysis of operating profit and operating margin to identify the most profitable areas.

### Time-Based Analysis

Analysis of sales by **year, quarter, and month** to identify trends and seasonal patterns.
